# Reference files

**Grounding material for content that must be factually correct.** Anything written about a law,
a constitution or a testing body's published rules is written **against a file in here**, never
from memory.

**Why this directory exists.** Aedwon asked for it on 4 August 2026, when the CSE content plan
was written: *"anything that needs grounding, save the file locally and have the plans reference
it always at all times when generating the content."*

**It is the same instinct as the never-invent-a-figure rule**, applied to facts rather than
figures. A wrong daily-question count is embarrassing. **A wrong statement about what the law
requires of a public official is a different order of problem**, and it is being told to someone
studying to become one.

---

## How to use these

1. **Every plan that generates content in one of these areas names its reference file**, and
   every generating run reads it before writing a line.
2. **A question must be answerable from its reference file.** If it is not, either the question
   is out of scope or the file is incomplete. **Both are worth reporting; neither is worth
   guessing through.**
3. **Where a file says a fact must be fetched, fetch it.** Those markers are not decoration:
   they mark exactly the places where a confident wrong answer is most likely.
4. **Where a file and its source disagree, the source wins.** Fix the file rather than working
   around it.

---

## What does not go in here

- **Anything that changes.** Who holds an office, a current programme, this year's figure.
- **Anything the app measures.** That is the student's own data and it is governed by the
  evidentiary rule, not by this directory.
- **Exam scope taken from a review center rather than the testing body.** Only the body's own
  published scope counts.
