## Core Concept

### Anyong Ang: Para sa Taong Itinatampok

Ang **panghalip panao** (personal pronoun) ay salitang pamalit sa ngalan ng tao. Nagbabago ang anyo nito ayon sa papel ng tao sa pangungusap at sa bilang kung isa o marami.

Gamitin ang anyong **ang** kapag ipinapalit sa taong itinatampok bilang paksa: *ako, ikaw, ka, siya, kami, tayo, kayo,* at *sila*. (Ginagamit ang *ikaw* sa unahan ng pangungusap tulad ng "Ikaw ang sumulat," at ang *ka* sa loob tulad ng "Sumulat ka.")

- "Si Ana ang dumating." -> "**Siya** ang dumating."

:::pair #pangkat-ng-ang
Right: Kabilang ang *siya* sa pangkat ng *ang* ("Siya ay dumating").
Wrong: Piliin ang *niya* o *kaniya* bilang anyong *ang*.
Parehong tumutukoy sa isang taong pinag-uusapan ang *siya, niya,* at *kaniya*, ngunit *siya* lamang ang nasa pangkat ng *ang*.
:::

:::check
Aling panghalip ang nasa pangkat ng *ang* para sa maraming taong pinag-uusapan: *(sila / nila / kanila)*?
:::answer
Ang sagot ay **Sila**. Ito ang pamalit sa paksang may *ang mga* o *sina* ("Sila ang dumating").
:::

### Anyong Ng: Para sa May-ari o Gumawa

Gamitin ang anyong **ng** (*ko, mo, niya, namin, natin, ninyo, nila*) para sa dalawang papel:

1. **May-ari** pagkatapos ng pangngalan: "aklat **ko**," "proyekto **nila**."
2. **Gumagawa** ng kilos kapag iba ang paksa: "Sinulat **niya** ang ulat." "Ipinakita **niya** ito."

Tiyakin muna kung sino ang gumawa at kung isa o marami siya.

:::pair #bilang-at-gumawa-sa-ng
Right: "Isang estudyante lamang ang nagdala ng proyekto; ipinakita niya ito sa buong klase."
Wrong: Gamitin ang *nila*, *namin*, o *ninyo* para sa iisang estudyante.
Kahit binanggit ang *buong klase*, iisang estudyante lamang ang nagpakita. Kailangan ang isahang anyong *ng* para sa pinag-uusapan: *niya*.
:::

:::check
Piliin ang tamang panghalip: Sina Ana at Ben ang gumawa ng ulat. Ipinasa *(sila / nila / kanila)* ang ulat kahapon.
:::answer
Ang sagot ay **Nila**. *Ang ulat* ang paksa, kaya anyong *ng* para sa maraming gumawa (*nila*) ang kailangan.
:::

### Anyong Sa: Para sa Tumanggap o Pinaglaanan

Gamitin ang anyong **sa** (*akin, iyo, kaniya, amin, atin, inyo, kanila*) pagkatapos ng *sa* o *para sa* upang ipakita kung kanino ibinigay o para kanino ang isang bagay.

- "Ibinigay ng kawani **kay Ana** ang resibo." -> "Ibinigay ng kawani **sa kaniya** ang resibo."

<!-- ILLUSTRATION: tatlong hilera na nagpapakita ng pangkat ng panghalip panao: anyong ang ("Siya ay dumating"), anyong ng ("Ipinakita niya ito"), at anyong sa ("Ibinigay sa kaniya ang resibo"), may palaso sa bawat papel -->

:::why
Bakit may tatlong anyo para sa iisang tao (*siya, niya, kaniya*)? Sa Filipino, ipinakikita ng anyo ng panghalip kung siya ang paksa (*ang*), ang gumagawa o may-ari (*ng*), o ang tatanggap (*sa*). Kaya hindi napagpapalit ang mga ito kahit iisang tao ang tinutukoy.
:::

:::pair #anyong-sa-para-sa-tatanggap
Right: Sa "Ibinigay ng tagapangasiwa sa mga boluntaryo," palitan ang "sa mga boluntaryo" ng *sa kanila*.
Wrong: Piliin ang *sila*, *nila*, o *para sa kaniya* para sa maraming tatanggap.
Ang mga boluntaryo ang maramihang tatanggap, kaya kailangan ang *sa kanila*, hindi paksang *sila*, tagaganap na *nila*, o isahang *kaniya*.
:::

:::check
Palitan ng panghalip ang "kay Ana" sa "Iniabot ni Marco ang susi kay Ana."
:::answer
Ang sagot ay **Sa kaniya**. Si Ana ang isang taong tumanggap ng susi, kaya anyong *sa* (*sa kaniya*) ang kapalit ng *kay Ana*.
:::

## Examples

### #1: Pagtukoy sa Anyong Ang

Alin sa *siya*, *niya*, *kaniya*, at *nila* ang kabilang sa pangkat ng *ang* para sa taong itinatampok sa pangungusap?

**Solution:**

1. Hanapin ang panghalip na maaaring pumalit sa *si Ana* o *ang bata* bilang paksa.
2. *Niya* at *nila* ay nasa pangkat ng *ng*, habang *kaniya* ay nasa pangkat ng *sa*.
3. Piliin ang **siya**.

**Check:** Subukan sa simula ng pangungusap: "**Siya** ay dumating" ay wasto, samantalang hindi maaaring pumalit ang *niya* o *kaniya* sa puwestong iyon.

### #2: Pagpili ng Tamang Panauhan at Bilang sa Anyong Ng

Piliin ang tamang panghalip: "Isang estudyante lamang ang nagdala ng proyekto; ipinakita ______ ito sa buong klase."

**Solution:**

1. Suriin ang papel ng patlang: *ito* (ang proyekto) ang paksa, kaya ang gumawa ng pagpapakita ay kailangan ng anyong *ng*.
2. Tukuyin kung sino at ilan ang nagpakita: isang estudyanteng pinag-uusapan (hindi ang nagsasalita at hindi ang kausap).
3. Piliin ang isahang anyong *ng* para sa pinag-uusapan: **niya**.

**Check:** Tiyakin ang tatlong bagay: anyong *ng* (gumawa), isa lamang (estudyante), at pinag-uusapan (*niya*), hindi *nila* (marami), *namin* (nagsasalita), o *ninyo* (kausap).

### #3: Anyong Sa para sa Maraming Tatanggap

Ang mga boluntaryo ang tatanggap ng mga kagamitan. Palitan ng panghalip ang "sa mga boluntaryo" sa "Ibinigay ng tagapangasiwa sa mga boluntaryo ang mga kagamitan."

**Solution:**

1. Tukuyin ang papel ng "sa mga boluntaryo": sila ang tatanggap ng mga kagamitan, kaya kailangan ang anyong **sa**.
2. Suriin ang bilang: marami ang *mga boluntaryo* at pinag-uusapan sila.

:::try
Tapusin ang huling hakbang: anong anyong *sa* ang ipapalit sa "sa mga boluntaryo"?
:::answer
Ang sagot ay **Sa kanila**: "Ibinigay ng tagapangasiwa sa kanila ang mga kagamitan."

**Check:** Suriin ang katumbas ng pinalitang parirala: *sa mga* (panandang *sa*, maramihan) + *boluntaryo* (pinag-uusapan) = *sa kanila*, hindi *sila*, *nila*, o isahang *kaniya*.
:::

## Speed Tricks & Shortcuts

Tiyakin muna ang papel bago ang bilang: *ang* kung siya ang paksa (*siya, sila*), *ng* kung gumawa o may-ari (*niya, nila*), at *sa* kung tumanggap (*sa kaniya, sa kanila*).

## Traps to Watch For

:::checklist
- Pagkilala sa anyo: huwag paghaluin ang *siya* (anyong *ang*), *niya* (anyong *ng*), at *kaniya* (anyong *sa*). {#pangkat-ng-ang}
- Salitang tulad ng *buong klase* sa paligid: itugma ang bilang sa mismong gumawa ng kilos. {#bilang-at-gumawa-sa-ng}
- Maramihang tatanggap gaya ng *sa mga boluntaryo*: gamitin ang anyong *sa* (*sa kanila*), hindi *sila*, *nila*, o *kaniya*. {#anyong-sa-para-sa-tatanggap}
:::
