## Core Concept

### Pagpili ng Aspekto Ayon sa Kalagayan ng Kilos

Maraming **pandiwa** (verb) ang nagsasaad ng kilos. Ang **aspekto** (stage of an action) ay nagsasabi kung tapos na, nagaganap pa, o gagawin pa ang kilos. Ihambing ang apat na anyo ng *kain* ayon sa kalagayan ng kilos:

1. **Perpektibo** (completed): tapos na, *kumain* ("Kumain na si Nena kanina.")
2. **Perpektibong katatapos** (recently completed): katatapos lamang, *kakakain lamang* o *katatapos lamang kumain* ("Kakakain lamang ni Nena bago siya umalis.")
3. **Imperpektibo** (ongoing): nagaganap pa o paulit-ulit, *kumakain* ("Kumakain pa si Nena habang naghihintay.")
4. **Kontemplatibo** (not yet begun): gagawin pa, *kakain* ("Kakain pa lamang siya mamaya.")

Iba-iba ang **panlapi** (affix) ng bawat pandiwa (tulad ng *nagluto, nagluluto, magluluto*), kaya suriin kung tapos na, nagaganap pa, o gagawin pa ang kilos sa pangungusap.

:::pair #aspekto-ayon-sa-kalagayan
Right: Hindi pa tapos kumain si Nena: "**Kumakain** pa si Nena habang hinihintay ang kaniyang kasama."
Wrong: Gamitin ang **Kumain**, **Kakain**, o **Kakakain lamang** kapag nasa hapag pa at hindi pa tapos si Nena.
Tapos na ang *kumain* at *kakakain lamang*, at hindi pa nagsisimula ang *kakain*. Dahil nagpapatuloy pa ang pagkain, *kumakain* ang tamang anyo.
:::

:::check
Nasa kusina pa si Marco at nasa gitna pa ng paghuhugas ng plato. Aling anyo ang angkop: *(naghugas / naghuhugas / maghuhugas)*?
:::answer
Ang sagot ay **Naghuhugas**. Nagaganap pa at hindi pa tapos ang paghuhugas ni Marco, kaya imperpektibo ang kailangan.
:::

### Bilang ng Paksa at Anyo ng Pandiwa

Ang **paksa** (subject) ang pinag-uusapan sa pangungusap.

Sa Ingles, may mga anyo ng pandiwa na nagbabago kapag maramihan ang paksa. Sa Filipino, karaniwang hindi nagbabago ang aspekto ng pandiwa dahil lamang dumami ang paksa:

- Isahan: "**Kumakain** ng tanghalian **ang kawani**."
- Maramihan: "**Kumakain** ng tanghalian **ang mga kawani**."

:::why
Bakit nananatili ang *kumakain* kahit marami na ang kawani? Sa dalawang pangungusap na ito, aspekto ang ipinakikita ng pandiwa, hindi ang bilang ng paksa. Karaniwang hindi kailangang baguhin ang pandiwa kapag dumami ang paksa. Ang *mga* sa paksa ang nagpapakita ng maramihan.
:::

:::pair #bilang-ng-paksa-at-pandiwa
Right: Gawing maramihan ang paksa ng "Kumakain ng tanghalian ang kawani": "**Kumakain ng tanghalian ang mga kawani.**"
Wrong: "**Kumain na ng tanghalian ang mga kawani.**" o "**Kakain pa lamang ng tanghalian ang mga kawani.**"
Dagdag na *mga* lamang ang pagbabago sa paksa. Kapag pinalitan ang *kumakain* ng *kumain na* o *kakain pa lamang*, binabago nito ang kalagayan ng kilos.
:::

:::check
Tapos na kahapon ang pagbibigay ng sertipiko ng guro. Gawing maramihan ang paksa: "___ ng sertipiko ang mga guro." Alin ang tama?

(A) Nagbigay

(B) Nagbibigay

(C) Magbibigay
:::answer
Ang sagot ay **A**: "Nagbigay ng sertipiko ang mga guro." Tapos na ang kilos, kaya *nagbigay* ang pandiwa. Dinagdagan lamang ng *mga* ang paksa.
:::

## Examples

### #1: Pagpili ng Aspekto Ayon sa Pangyayari

Nasa mesa si Rico at hindi pa tapos sa pagtahi ng kurtina. Aling anyo ng *tahi* ang angkop: *(tumahi / tumatahi / tatahi)* sa "___ pa si Rico ng kurtina habang tumatawag ang kapatid niya"?

**Solution:**

1. Ang pahiwatig ay "hindi pa tapos": nagpapatuloy pa ang pagtahi.
2. Imperpektibo ang anyo: "**Tumatahi** pa si Rico ng kurtina habang tumatawag ang kapatid niya."

**Check:** Ang *tumatahi* ay inulit ang *ta*, kaya hindi pa tapos ang pagtahi. Ang *tumahi* ay walang inulit na bahagi at tapos na ang kilos.

### #2: Pagbabago ng Bilang ng Paksa

Gawing maramihan ang paksa ng "Nagbabasa ng aklat ang guro." Panatilihin ang kalagayan ng kilos. Alin ang wastong pagbabago?

**Solution:**

1. Hanapin ang paksa at gawing maramihan: *ang guro* -> *ang mga guro*.
2. Iwan ang pandiwa: "**Nagbabasa ng aklat ang mga guro.**"

**Check:** Ihambing ang dalawang pangungusap: *mga* lamang ang bagong salita.

### #3: Tatlong Kalagayan sa Iisang Salitang-Ugat

Punan ng angkop na anyo ng *linis* ang bawat patlang: "___ si Lea ng silid kagabi. ___ pa siya ng bintana ngayon. ___ si Ben ng bakuran bukas ng umaga."

**Solution:**

1. Tapos na kagabi ang unang kilos: "**Naglinis** si Lea ng silid kagabi."
2. Nagaganap pa ngayon ang ikalawa: "**Naglilinis** pa siya ng bintana ngayon."

:::try
Alin ang akma sa ikatlong patlang: *naglinis* o *maglilinis*? Ano ang buong pangungusap?
:::answer
Ang sagot ay **Maglilinis**: "Maglilinis si Ben ng bakuran bukas ng umaga."

**Check:** Palitan ang *bukas* ng *kahapon*: "Naglinis si Ben ng bakuran kahapon." Ang *bukas* ang nagpapakitang gagawin pa ang kilos.
:::

## Speed Tricks & Shortcuts

Itanong muna kung tapos na, nagaganap pa, o gagawin pa ang kilos. Kapag bilang lamang ng paksa ang binago, karaniwang panatilihin ang pandiwa.

## Traps to Watch For

:::checklist
- Nagpapatuloy na kilos gaya ng hindi pa tapos sa hapag: piliin ang imperpektibo (*kumakain*), hindi *kumain*, *kakain*, o *kakakain lamang*. {#aspekto-ayon-sa-kalagayan}
- Maramihang paksa na may *mga*: karaniwang panatilihin ang anyo ng pandiwa dahil bilang lamang ng paksa ang nagbago. {#bilang-ng-paksa-at-pandiwa}
:::
