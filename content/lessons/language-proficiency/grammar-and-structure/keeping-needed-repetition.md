## Core Concept

### When "Again" Adds Needed Meaning

Words that look redundant on paper can carry real meaning depending on what happened earlier. Look at **repeat again** in two situations:

1. **No earlier repeat happened:** A speaker says something once, and a listener misses it. In *"Could you please repeat again what you just said?"*, *repeat* already means say once more, so *again* usually adds nothing. Cut it: *"Could you please repeat what you just said?"*
2. **An earlier repeat already happened:** An officer gave an instruction, then repeated it when asked. A late arrival missed both readings. In *"Please repeat the instruction again for the late arrival,"* *again* can mark **one more repeat** after the repeat already given. Some style guides call *repeat again* redundant in both cases, so follow the timeline the question gives.

<!-- FIGURE WANTED: three-step timeline left to right: Step 1 "First reading" -> Step 2 "First repeat (already repeated)" -> Step 3 "Late arrival arrives: 'repeat again' = a further repeat" -->

:::why
Why can *repeat again* be wrong in one case and right in another? *Repeat* means say one more time. On a first repeat, *repeat* alone does the job; after an earlier repeat, *again* can mark a further repeat beyond the first one.
:::

:::pair #cutting-or-changing-first-repeat
Right: With no earlier repetition, revise *"Could you please repeat again what you just said?"* to *"Could you please repeat what you just said?"*
Wrong: Revise it to *"Could you please repeat again once more what you just said?"* or *"Could you please change what you just said into a new idea?"*
Adding *once more* piles on extra filler, while asking to *change* the words alters the request. With no prior repeat, usually drop *again*.
:::

:::check
A teacher mumbled a date once, and a student who missed it asks. Which is concise: *"Please repeat the date again"* or *"Please repeat the date"*?
:::answer
The answer is **"Please repeat the date."** No earlier repeat happened yet, so *repeat* alone asks to say it a second time.
:::

### Reading the Context Before Editing

Check the timeline of events before you cut *again*:

1. Count whether the action happened once or was already repeated.
2. *Again* can stay when it marks a further repeat beyond an earlier repeat; cut it when it adds no new step.

:::pair #missing-prior-repeat
Right: After an officer gave an instruction and already repeated it once, in *"Please repeat the instruction again for the late arrival,"* *again* means *"It requests a further repeat."*
Wrong: Claim *again* means *"It says the instruction has never been repeated."* or *"It requires the officer to change the instruction."*
*Again* does not erase the earlier repeat and does not ask for new wording. It adds one more repeat beyond the repeat already given.
:::

:::check
A pilot announced a gate change, then repeated it twice. Now a late passenger asks, *"Please repeat the gate change again."* By that timeline, what does *again* mark?
:::answer
**Another repeat after the two already given.** *"Please repeat the gate change again"* asks for one more saying, so *again* adds a step.
:::

## Examples

### #1: Cutting Needless "Again" on a First Repeat

Nobody has repeated the room number yet. For concise formal writing, revise: *"Please repeat again the room number."*

**Solution:**

1. Check the context: no earlier repeat has happened.
2. *Repeat* already means say the same words once more, so cut *again*.

Correct sentence: **"Please repeat the room number."**

**Check:** The revised sentence still asks for the same words.

### #2: Keeping "Again" After an Earlier Repeat

Mara read a notice aloud. At Ben's request, she repeated it. Ben still could not hear. By that timeline, does *again* add meaning in *"Please repeat it again"*?

**Solution:**

1. Count prior readings: (1) first reading, (2) first repeat for Ben.
2. Ben now wants a **second** repeat, so *again* adds that further step and can stay: **"Please repeat it again."**

**Check:** Retell the sequence as actions: Mara's first reading, her first repeat, then the second repeat Ben now asks for. *Again* marks that last step.

### #3: Reading a Longer Timeline

A coach explained a drill once, and no one asked for a repeat. Sam came late. For concise formal writing, revise *"Could you repeat the drill again for Sam?"*

**Solution:**

1. Count what happened before Sam arrived: (1) one explanation, no repeat.

:::try
Finish the last step: delete one word and keep the same meaning.
:::answer
**"Could you repeat the drill for Sam?"** The coach has not repeated the drill yet, so *repeat* alone asks for the first repeat.

**Check:** Compare "repeat the drill for Sam" with "repeat the drill again for Sam." Here, with no earlier repeat, both ask for the same single repeat.
:::

## Speed Tricks & Shortcuts

Before cutting *again* after *repeat*, count how many times the words were already spoken. Zero prior repeats usually means cut *again*; one or more prior repeats means *again* can stay.

## Traps to Watch For

:::checklist
- First-time repeat request: usually cut *again* (do not pile on *once more* or change the request into a new idea). {#cutting-or-changing-first-repeat}
- Request after an earlier repeat: *again* can stay because it marks a further repeat, not a first repeat or a new instruction. {#missing-prior-repeat}
:::
