## Core Concept

### Mga Gamit ng Ng

Magkaiba ang gamit ng **ng** at **nang**. Tingnan ang papel ng kasunod na salita sa buong pangungusap bago pumili.

Ginagamit ang **ng** sa apat na karaniwang ayos:

1. **Bagay na tinutukoy ng kilos**: "Kumain **ng** mangga si Ana." *Mangga* ang kinain.
2. **Pagmamay-ari o ugnayan**: "Malinis ang bahay **ng** guro." Kanino ang bahay?
3. **Dami o sukat ng bagay**: "Bumili siya **ng** tatlong kilo **ng** bigas."
4. **Bahagi ng araw sa oras**: "Magsisimula tayo sa alas-singko **ng** hapon." Sinasabi ng *hapon* ang bahagi ng araw.

:::pair #pagmamay-ari
Right: Ang bahay ng aking lola ay malapit sa simbahan.
Wrong: Ang bahay nang aking lola ay malapit sa simbahan.
Pag-aari ng lola ang bahay. Ang *ng* ang nagpapakita ng ugnayang ito.
:::

:::pair #dami
Right: Bumili siya ng tatlong mangga sa palengke.
Wrong: Bumili siya nang tatlong mangga sa palengke.
Ang *tatlong mangga* ay dami ng binili. Kaya *ng* ang kailangan.
:::

:::check
Piliin ang tamang salita: "Nagdala si Carlo *(ng / nang)* dalawang kahon ng aklat."
:::answer
Ang sagot ay **ng**. Tumutukoy ang *dalawang kahon* sa bagay at daming dinala, kaya *ng* ang tamang gamit.
:::

### Mga Gamit ng Nang

Ginagamit ang **nang** sa tatlong karaniwang ayos:

1. **Paraan o tindi ng kilos**: "Tumakbo **nang** mabilis ang aso." Inilalarawan ng *mabilis* kung paano tumakbo ang aso.
2. **Katumbas ng "noong"**: "**Nang** dumating siya, nagsimula ang pulong."
3. **Kilos na inuulit**: "Takbo **nang** takbo ang bata sa bakuran."

May iba pang gamit ang *nang*, gaya ng katumbas ng *upang*.

:::pair #noong
Right: Nang dumating ang bus, tumayo ang mga pasahero.
Wrong: Ng dumating ang bus, tumayo ang mga pasahero.
Katumbas ng *noong* ang *nang* dito. Hindi ito *ng*.
:::

:::check
Piliin ang tamang salita: "Sumagot *(ng / nang)* magalang ang mag-aaral."
:::answer
Ang sagot ay **nang**. Sinasabi ng *magalang* kung paano sumagot ang mag-aaral, kaya *nang* ang gamit sa paraan ng kilos.
:::

## Examples

### #1: Paraan ng Kilos

Punan ang patlang: "Tumakbo ______ mabilis ang aso nang makita nito ang pusa."

A) ng  
B) nang  
C) na  
D) may

**Solution:**

1. Sinasabi ng *mabilis* kung paano tumakbo ang aso.
2. Gamitin ang **nang**: "Tumakbo nang mabilis ang aso nang makita nito ang pusa." Sagot: **B**.

**Check:** Itanong: paano tumakbo ang aso? Mabilis.

### #2: Bagay at Pagmamay-ari

Piliin ang tamang pares: "Bumili ______ mangga si Ana para sa anak ______ guro."

A) ng; ng  
B) nang; ng  
C) ng; nang  
D) nang; nang

**Solution:**

1. Mangga ang binili, kaya *ng* ang unang sagot.
2. Ipinakikita ng *anak ng guro* ang ugnayan ng anak at guro, kaya **ng** din ang ikalawa: "Bumili ng mangga si Ana para sa anak ng guro." Sagot: **A**.


### #3: Dami o Sukat

Punan ang patlang: "Bumili si Liza ng tatlong kilo ______ bigas."

A) nang  
B) ng  
C) na  
D) may

**Solution:**

1. Ang *tatlong kilo* ay nagsasabi ng dami o sukat.
2. Gamitin ang **ng**: "Bumili si Liza ng tatlong kilo ng bigas." Sagot: **B**.

**Check:** Bigas ang binili, at tatlong kilo ang sukat nito.

### #4: Pahayag ng Oras

Punan ang patlang: "Nagsimula ang programa sa alas-tres ______ hapon."

A) nang  
B) ng  
C) na  
D) may

**Solution:**

1. Ang *hapon* ay bahagi ng araw.
2. Gamitin ang **ng**: "Nagsimula ang programa sa alas-tres ng hapon." Sagot: **B**.


### #5: Oras at Paulit-ulit na Kilos

Piliin ang tamang pares: "______ dumating ang bus, tawag ______ tawag si Mila sa kapatid niya."

A) Ng; ng  
B) Nang; ng  
C) Ng; nang  
D) Nang; nang

**Solution:**

1. Ang unang patlang ay may kahulugang *noong*, kaya *nang* ang kailangan.
2. Inuulit ang kilos sa *tawag nang tawag*, kaya **nang** din ang ikalawa: "Nang dumating ang bus, tawag nang tawag si Mila sa kapatid niya." Sagot: **D**.

**Check:** Palitan ng *noong* ang unang *nang*. Tama pa rin ang kahulugan.

### #6: Pangungusap na may Tatlong Patlang

Piliin ang tamang hanay: "Bumili ______ saging si Rosa, at ______ dumating ang guro, nagsalita siya ______ malumanay."

A) ng; nang; nang  
B) nang; ng; nang  
C) ng; ng; nang  
D) ng; nang; ng

**Solution:**

1. Bagay na binili ang *saging*, kaya *ng* ang unang patlang.
2. May kahulugang *noong* ang ikalawang patlang, kaya *nang* ang kailangan.

:::try
Tapusin ang huling hakbang: tukuyin ang ikatlong patlang at piliin ang tamang hanay.
:::answer
Ang sagot ay **A**. Sinasabi ng *malumanay* kung paano nagsalita si Rosa, kaya *nang* ang ikatlong patlang.

**Check:** Basahin nang buo: "Bumili ng saging si Rosa, at nang dumating ang guro, nagsalita siya nang malumanay." Bagay ang *saging*, *noong* ang *nang dumating*, at paraan ang *nang malumanay*.
:::

## Speed Tricks & Shortcuts

Tingnan ang buong parirala. Alamin kung bagay, ugnayan, dami, oras, paraan ng kilos, *noong*, o kilos na inuulit ang tinutukoy.

## Traps to Watch For

:::checklist
- Pagmamay-ari, ugnayan, o bahagi ng araw gaya ng alas-tres *ng* hapon: gamitin ang *ng*. {#pagmamay-ari}
- Dami o sukat ng bagay gaya ng tatlong mangga: gamitin ang *ng*. {#dami}
- Kahulugang *noong*, paraan o tindi ng kilos, o kilos na inuulit: karaniwang *nang* ang gamit. {#noong}
:::
