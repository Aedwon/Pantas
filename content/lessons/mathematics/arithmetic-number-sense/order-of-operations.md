## Core Concept

When an expression has several operations, use the standard order of operations so the expression has one consistent value.

This order is often remembered as **PEMDAS** or **GEMDAS**.

In exam questions, **evaluate** means find the final number answer.

First, evaluate **G**rouping symbols or **P**arentheses. This includes parentheses $()$, square brackets $[]$, curly braces $\{\}$, and fraction bars.

Second, evaluate **E**xponents and roots. An exponent tells how many times a base is used as a factor. For example, $3^2=3\times3$.

A **root** reverses a power. For example, $\sqrt{49}=7$ because $7^2=49$.

Third, evaluate **M**ultiplication and **D**ivision from left to right. Multiplication does not automatically come before division.

Last, evaluate **A**ddition and **S**ubtraction from left to right. Addition does not automatically come before subtraction.

### Signed Integers Inside Expressions

A **signed integer** is a whole number with a positive or negative sign. The **absolute value** of a number is its distance from $0$, so $|-6|=6$.

When adding integers with the same sign, add their absolute values and keep the sign. When the signs differ, subtract the smaller absolute value from the larger one and keep the sign of the number with the larger absolute value. If the absolute values are equal, the sum is $0$.

Subtracting a number is the same as adding its opposite. For multiplication and division, equal signs give a positive answer, while different signs give a negative answer. Division by $0$ is undefined.

When substituting a negative value for a variable, put the value in parentheses. This keeps the negative sign attached to the number before powers and other operations are applied.

## Mnemonics & Memory Aids

To remember PEMDAS, use:

> Please Excuse My Dear Aunt Sally.

If you prefer GEMDAS:

> Giant Elephants March Down A Street.

The important detail is that multiplication and division share the same priority, as do addition and subtraction. Within each pair, work from left to right.

## Examples

### #1: The Left-to-Right Rule

Evaluate the expression: $16 \div 4 \times 2 + 3$.

**Solution:**

1. There are no grouping symbols, exponents, or roots to evaluate first.
2. Work through division and multiplication from left to right.

$$16 \div 4 = 4$$

$$4 \times 2 = 8$$

3. Add last.

$$8 + 3 = 11$$

### #2: Signed Integers

Evaluate $18-6\times(-3)+8\div(-2)$.

**Solution:**

1. Multiply and divide before adding or subtracting.

$$6\times(-3)=-18$$

$$8\div(-2)=-4$$

2. Substitute those results into the expression.

$$18-(-18)+(-4)$$

3. Subtracting $-18$ means adding $18$.

$$18+18-4=32$$

### #3: Nested Grouping Symbols

In exam questions, **simplify** means write an equivalent expression in a simpler form.

Simplify: $2[5+3(4-2)^2]-10$.

**Solution:**

1. Start with the innermost parentheses.

$$4-2=2$$

2. Evaluate the exponent.

$$2^2=4$$

3. Multiply inside the brackets.

$$3\times4=12$$

4. Add inside the brackets.

$$5+12=17$$

5. Multiply by the $2$ outside the brackets, then subtract $10$.

$$2(17)-10=34-10=24$$

### #4: Evaluating a Root

Evaluate $\sqrt{81}+2^3\times3$.

**Solution:**

1. Evaluate the root and exponent first.

$$\sqrt{81}=9$$

$$2^3=8$$

2. Multiply before adding.

$$8\times3=24$$

3. Add the remaining terms.

$$9+24=33$$

### #5: Fraction Bars as Grouping Symbols

What is the value of $\dfrac{3^2+4\times5}{6-2^3+4}$?

**Solution:**

1. Treat the numerator and denominator as grouped expressions.
2. Evaluate the numerator.

$$3^2+4\times5=9+20=29$$

3. Evaluate the denominator from left to right after the exponent.

$$6-2^3+4=6-8+4=2$$

4. Divide the two results.

$$\dfrac{29}{2}$$

### #6: Algebraic Evaluation

If $x=-2$ and $y=3$, evaluate $x^2-3xy+\dfrac{12}{x}$.

**Solution:**

1. Substitute the values, using parentheses around the negative value of $x$.

$$(-2)^2-3(-2)(3)+\dfrac{12}{-2}$$

2. Evaluate powers, multiplication, and division.

$$4-(-18)-6$$

3. Finish the addition and subtraction.

$$4+18-6=16$$

## Speed Tricks & Shortcuts

Addition and subtraction signs can help you see large additive terms. In an expression such as

$$5\times4-3^2+20\div5,$$

you can evaluate the higher-priority pieces first:

$$20-9+4=15.$$

This is safe as long as you do not break apart an operation that has higher priority or ignore grouping symbols.

## Traps to Watch For

### #1: Multiplication Before Division

> Do not always multiply before dividing. Work from left to right when multiplication and division have the same priority.

For $10\div2\times5$:

$$10\div2\times5=5\times5=25.$$

### #2: Negative Bases and Exponents

> $-3^2$ is not the same as $(-3)^2$.

In $(-3)^2$, the parentheses make $-3$ the base, so the value is $9$. In $-3^2$, the exponent applies to $3$ before the leading negative sign, so the value is $-9$.

### #3: Addition Before Subtraction

> Addition does not automatically come before subtraction.

For $10-4+2$, work from left to right:

$$10-4+2=6+2=8.$$
