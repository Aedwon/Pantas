## Core Concept

### Natural, Whole, and Integer Sets

Numbers belong to nested sets, like smaller boxes sitting inside larger boxes.

- **Natural numbers** are the counting numbers $1,2,3,\dots$. Some books include $0$, so follow the rule stated in the question.
- **Whole numbers** add $0$ to the counting numbers: $0,1,2,3,\dots$. Negative numbers are not whole numbers. A fraction is whole only when it equals a whole number, such as $\dfrac{6}{3}=2$, not $\dfrac{1}{2}$.
- **Integers** include all whole numbers and their opposites: $\dots,-2,-1,0,1,2,\dots$.

Sort $5$, $0$, and $-4$ by the three sets above. The number $5$ is natural, whole and an integer.

The number $0$ is whole and an integer. It is not natural when natural numbers start at $1$. The number $-4$ is an integer. It is not a natural or whole number. The next section adds the rational and real sets.

:::pair #negative-whole-number
Right: $-1$ is an integer, not a whole number.
Wrong: $-1$ is a whole number.
Whole numbers start at $0$, so a negative number is not whole. When natural numbers start at $1$, only $0$ is whole but not natural.
:::

### Rational, Irrational, and Real Numbers

A **rational number** can be written as a fraction $\dfrac{p}{q}$ of two integers, with $q\ne 0$. Every integer $n$ equals $\dfrac{n}{1}$, so every integer is rational. Decimals that stop (like $0.75$) or repeat forever (like $0.333\dots$) are rational too.

An **irrational number** is a real number that cannot be written as an integer fraction. Its decimal goes on forever without repeating. Common examples are $\pi$ and square roots of non-negative integers that are not perfect squares, such as $\sqrt{2}$ and $\sqrt{7}$.

Rational and irrational numbers never overlap. Together, they make up all **real numbers**.

Now finish the sort of $5$, $0$ and $-4$. Each one is an integer, so each is rational: $5=\dfrac{5}{1}$, $0=\dfrac{0}{1}$ and $-4=\dfrac{-4}{1}$. Each rational number is also a real number. So $5$ is a rational number and a real number as well, $0$ is too, and $-4$ is too.

Decide whether $\sqrt{9}$ and $\sqrt{7}$ are rational:

$$\sqrt{9}=3$$

$$3=\dfrac{3}{1}$$

$$\sqrt{7}\approx 2.64575\dots$$

Because $9$ is a perfect square, $\sqrt{9}$ equals $3$, so it is rational. Because $7$ is not a perfect square, $\sqrt{7}$ never ends or repeats, so it is irrational.

For positive numbers, $\sqrt{a}\times\sqrt{b}=\sqrt{ab}$. So two irrational square roots can still multiply to a rational number if the numbers under the roots multiply to a perfect square:

$$\sqrt{2}\times\sqrt{8}=\sqrt{16}$$

$$\sqrt{16}=4$$

:::why
Why is every decimal that stops rational? Place value turns it straight into an integer fraction: $0.75=\dfrac{75}{100}$, and $\dfrac{75}{100}=\dfrac{3}{4}$.
:::

:::pair #perfect-square-root
Right: $\sqrt{9}=3$, which is rational.
Wrong: $\sqrt{9}$ is irrational because it has a square root sign.
Simplify the square root first. A square root of a positive integer is irrational only when the number inside is not a perfect square.
:::

:::pair #decimal-is-irrational
Right: $0.75=\dfrac{3}{4}$, so $0.75$ is rational.
Wrong: $0.75$ is irrational because it is a decimal.
Only decimals that never end and never repeat are irrational. A decimal that stops, like $0.75$, always writes as a fraction.
:::

:::check
Which whole number between $20$ and $30$ has a rational square root?
:::answer
The answer is $25$. It is a perfect square, since $5^2=25$, so $\sqrt{25}=5$. The other whole numbers from $21$ to $29$ are not perfect squares.
:::

## Mnemonics & Memory Aids

Under this lesson's convention, each set sits inside the next:

> Natural, Whole, Integer, Rational, Real.

Irrational numbers sit inside Real numbers beside Rational numbers, never inside them.

## Examples

### #1: Classifying Number Sets

Which statement is false?

A) Every integer is rational.

B) $\sqrt{12}\times\sqrt{3}$ is irrational.

C) Every irrational number is real.

D) A repeating nonterminating decimal is rational.

**Solution:**

1. Check A: every integer $n$ can be written as $\dfrac{n}{1}$, which is an integer fraction, so A is true.
2. Check C: real numbers consist of rational and irrational numbers together, so C is true.
3. Check D: a repeating decimal like $0.333\dots=\dfrac{1}{3}$ can be written as an integer fraction, so D is true.

:::try
Finish the last step. Check B: put $\sqrt{12}\times\sqrt{3}$ under one root. What is its exact value?
:::answer
The answer is $6$. $\sqrt{12}\times\sqrt{3}=\sqrt{36}=6$. Since $6$ is rational, B is false, so B is the false statement.
:::

## Traps to Watch For

:::checklist
- Natural numbers and whole numbers: follow the question's convention for $0$, and keep negatives out of whole numbers. {#negative-whole-number}
- Square roots: simplify first to check for a perfect square, so $\sqrt{9}=3$ is rational. {#perfect-square-root}
- Decimals that end or repeat: write them as fractions, so $0.75=\dfrac{3}{4}$ is rational. {#decimal-is-irrational}
:::
