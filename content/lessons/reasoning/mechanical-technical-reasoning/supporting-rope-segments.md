## Core Concept

A **movable pulley** moves with the load. **Tension** is the pull along a rope.

If one rope runs through the whole system and there is no friction, its tension is the same everywhere. Some systems use several ropes, and each rope has its own tension. This lesson counts segments only for one-rope systems.

Each rope **segment** is a straight length of rope between two turns or ties. Each segment that pulls on the moving load carries that same tension. This gives a reliable rule for an ideal system with one rope and segments that hang straight up:

> **Ideal MA = the number of rope segments that pull directly on the moving load.**

Count a segment if it is tied to the moving pulley or its frame, or runs around the moving pulley. A segment that runs from a fixed pulley to your hand does not pull on the load, so do not count it. If your hand pulls the end that leaves the moving pulley, that end counts.

Two supporting segments give MA $2$: the effort is half the load when the load is held still or moves at a steady speed, and the free end moves twice as far as the load. Three segments give MA $3$, four give MA $4$, and so on. The rule fails if the segments pull at a slant, because only part of each pull lifts the load.

Do not count pulleys. Systems with the same number of pulleys can have different numbers of supporting segments.

## Examples

### #1: Two Supporting Rope Segments

A $60\text{ kg}$ mass is lifted by an ideal movable-pulley arrangement in which **two rope segments support the moving load**. Approximately what effort is required if $g=9.8\text{ m/s}^2$, and how much rope must be pulled to raise the load $2\text{ m}$?

**Solution:**

1. Load weight:

$$W=mg=(60)(9.8)=588\text{ N}.$$

2. Two supporting segments give ideal mechanical advantage $2$:

$$F_\text{effort}=\dfrac{588}{2}=294\text{ N}.$$

3. The effort end must move twice the load distance, so raising the load $2\text{ m}$ requires pulling about $4\text{ m}$ of rope.

## Traps to Watch For

### #1: Calling a 50 kg Mass a 50 kg Force

> Kilograms measure mass. Use newtons for force: on Earth, $50\text{ kg}$ weighs $490\text{ N}$.

Test questions often give a mass and ask for a force. Multiply by $g$ first.
