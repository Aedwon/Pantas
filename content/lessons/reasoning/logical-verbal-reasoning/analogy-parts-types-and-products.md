## Core Concept

### Using a Short Sentence

A **word analogy** matches the link between two words with a second pair. It appears as "A is to B as C is to D" or $A:B::C:D$.

Turn the first pair into a short sentence, then test that sentence on each choice.

1. Look at *spoon : utensil* and *apple : ______*.
2. Make a sentence: "A spoon is a type of utensil."
3. Test it: "An apple is a type of **fruit**."

:::check
Complete *jacket : clothing* as *sandal : ______* (*leather*, *foot*, *footwear*, *closet*).
:::answer
The answer is **footwear**. A jacket is a type of clothing, and a sandal is a type of footwear.
:::

### Part and Whole

A **part-to-whole** pair moves from a piece to the whole object (*petal : flower*). A **whole-to-contents** pair moves the other way (*library : books*).

Keep the same direction and level of closeness.

1. For *petal : flower* and *branch : ______*: a petal is part of a flower.
2. A branch is part of a **tree**.

:::why
Why is *forest* wrong for *branch*? A forest holds trees, so it skips a level. A branch sits on a tree, just as a petal sits on a flower.
:::

:::pair #reverse-part-whole
Right: "Library is to books" matches **Archive is to records**.
Wrong: "Library is to books" matches **Pages is to novel**.
Check which item holds the other. *Pages is to novel* reverses the container-to-contents direction.
:::

:::check
Complete *finger : hand* as *toe : ______* (*shoe*, *foot*, *leg*, *nail*).
:::answer
The answer is **foot**. A finger is part of a hand, and a toe is part of a foot.
:::

### Category or Type

A **category** pair moves from a specific member to its group (*rose : flower*).

1. For *sonnet : poem* and *waltz : ______* (ballroom dance): a sonnet is a type of poem.
2. A waltz is a type of **dance**.

:::pair #material-not-category
Right: "Hammer is to tool" matches **oak tree : tree**.
Wrong: "Hammer is to tool" matches **oak tree : wood**.
An oak tree gives wood, while *tree* names its category. Ask "Is it a type of?" to reject materials.
:::

:::check
Complete *salmon : fish* as *eagle : ______* (*feather*, *nest*, *bird*, *sky*).
:::answer
The answer is **bird**. A salmon is a type of fish, and an eagle is a type of bird.
:::

### Cause or Product

A **cause-or-product** pair moves from an action or source to what it directly produces (*fire : ash*).

1. For *evaporation : vapor* and *freezing : ______* (for water): evaporation turns water into vapor.
2. Freezing turns water into **ice**.

:::pair #nearby-event-not-product
Right: "Fire is to ash" matches **lightning : thunder**.
Wrong: "Fire is to ash" matches **lightning : downpour**.
Rain often happens during storms, yet lightning causes thunder directly by heating air.
:::

:::check
Complete *spark : flame* as *seed : ______* (*soil*, *water*, *sprout*, *farmer*).
:::answer
The answer is **sprout**. A spark produces a flame, and a seed produces a sprout.
:::

## Examples

### #1: Category

Hammer is to tool as oak tree is to ______.

(A) Wood (B) Tree (C) Leaf (D) Forest

**Solution:**

1. Sentence: "A hammer is a type of tool."
2. Test choices: an oak tree is a type of **tree**.
3. Wood is material, leaf is a part, and forest is a group of trees.

The answer is **(B) Tree**.

**Check:** "An oak tree is a type of tree" matches the exact sentence and direction.

### #2: Part to Whole

Wheel is to bicycle as page is to ______.

(A) Pencil (B) Book (C) Reader (D) Ink

**Solution:**

1. Sentence: "A wheel is part of a bicycle."
2. Test choices: a page is part of a **book**.
3. Pencil and ink are tools, and reader is a person.

The answer is **(B) Book**.

**Check:** Both pairs go from part (*wheel*, *page*) to whole (*bicycle*, *book*).

### #3: Cause or Product

Fire is to ash as grinding grain is to ______.

(A) Flour (B) Field (C) Spoon (D) Seed

**Solution:**

1. Sentence: "Fire produces ash."
2. Test choices: grinding grain produces **flour**.
3. Field is a place, spoon is a tool, and seed is the starting input.

The answer is **(A) Flour**.

**Check:** Fire leaves ash, and grinding grain produces flour.

### #4: Whole to Contents

Which pair best matches the ordered relationship in "Library is to books"?

(A) Borrower is to books (B) Pages is to novel (C) Archive is to records (D) Catalog is to librarian

**Solution:**

1. Sentence: "A library holds books."
2. Drop (A) and (D): borrower and librarian name users, not contents.
3. Drop (B): *pages* go inside a *novel*, reversing the direction.

:::try
Finish the last step: test choice (C) in the sentence "______ holds ______."
:::answer
The answer is **(C) Archive is to records**. An archive holds records, keeping the container-to-contents direction.

**Check:** Flipping (B) gives "Pages hold a novel," which is false.
:::

## Speed Tricks & Shortcuts

Write one short sentence for the first pair before reading the choices. Keep its exact direction as you plug in each choice.

## Traps to Watch For

:::checklist
- Picking material instead of category: ask "Is it a type of?" so *oak tree* pairs with *tree*, not *wood*. {#material-not-category}
- Reversing part and whole: keep the exact order, so *library : books* matches *archive : records*, not *pages : novel*. {#reverse-part-whole}
- Picking a nearby event instead of a direct result: ask what the first word produces, so *lightning* pairs with *thunder*, not *downpour*. {#nearby-event-not-product}
:::
