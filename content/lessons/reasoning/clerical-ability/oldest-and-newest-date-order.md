## Core Concept

### Oldest-First vs. Newest-First Direction

**Chronological filing** sorts records by date. A system may ask for either direction:

- **Oldest to newest**: the earliest calendar date goes first.
- **Newest to oldest** (also called **reverse chronological order**): the most recent date goes first, at the top of the folder.

Check which direction the question names before looking at the dates.

Find the order of January $3$, $2025$ and December $31$, $2024$ in both directions:

- The years differ first: $2024$ comes before $2025$.
- Oldest to newest: December $31$, $2024$, then January $3$, $2025$.
- Reverse chronological (newest to oldest): January $3$, $2025$ on top, then December $31$, $2024$.

:::pair #wrong-date-direction
Right: in reverse chronological order, put the **most recent date** ($2025\text{-}01\text{-}08$) at the top
Wrong: put the **earliest historical date** ($2024\text{-}12\text{-}20$) at the top
"Reverse chronological" starts with the newest record, not the oldest. Check the direction first.
:::

### Year, Then Month, Then Day

In these questions, compare complete dates in three steps, from largest calendar unit to smallest:

1. Compare the **year** first.
2. If the years match, compare the **month** (January $= 1$ through December $= 12$).
3. Compare the **day** only when both the year and the month match.

Two records that show the same month and year, such as two "May $2025$" records, cannot be ordered against each other until their day dates are known. If a registry names another key first, such as file number, use the date only when that key matches.

Find the oldest-to-newest order of June $15$, $2025$, July $1$, $2025$, and June $10$, $2025$:

- Step $1$ (year): all three are in $2025$ (tie).
- Step $2$ (month): June ($6$) comes before July ($7$), so July $1$, $2025$ is last.
- Step $3$ (day, for the June dates): day $10$ comes before day $15$.
- Order: June $10$, $2025$; June $15$, $2025$; July $1$, $2025$.

:::pair #month-beats-year
Right: in newest-first order, January $3$, $2025$ ($2025\text{-}01\text{-}03$) comes before December $31$, $2024$ ($2024\text{-}12\text{-}31$)
Wrong: December $31$, $2024$ ($2024\text{-}12\text{-}31$) comes first because December is the end of the year
December $31$ is late inside $2024$, but $2025$ is a newer year. Compare the year before the month or day.
:::

:::pair #day-beats-month
Right: in oldest-first order, June $15$, $2025$ ($2025\text{-}06\text{-}15$) comes before July $1$, $2025$
Wrong: July $1$, $2025$ ($2025\text{-}07\text{-}01$) comes before June $15$, $2025$ because day $1$ is smaller than day $15$
Day $1$ looks small, but July is later than June. Compare days only after the year and month tie.
:::

:::why
Why does a calendar compare year, then month, then day? One year holds $12$ months, and one month holds at most $31$ days. A later year outweighs any month or day of the earlier year.
:::

:::check
A folder is filed newest to oldest. Arrange September $14$, $2024$; December $2$, $2023$; September $4$, $2024$; and September $21$, $2024$.
:::answer
The answer is **September $21$, $2024$; September $14$, $2024$; September $4$, $2024$; December $2$, $2023$**. December $2023$ is last because $2023$ is the oldest year. The three $2024$ dates tie on month, so the days decide, newest first: $21 > 14 > 4$.
:::

## Examples

### #1: Oldest to Newest

Arrange these dates from oldest to newest: March $15$, $2024$; January $20$, $2024$; November $5$, $2023$; and February $10$, $2025$.

**Solution:**

1. Compare the years first: $2023$ is earliest, then the two $2024$ dates, then $2025$.
2. Put November $5$, $2023$ first and February $10$, $2025$ last.
3. The two $2024$ dates first differ in the month: January comes before March.
4. The order is November $5$, $2023$; January $20$, $2024$; March $15$, $2024$; February $10$, $2025$.

### #2: Reverse Chronological Order

Place these records in reverse chronological order: July $8$, $2024$; July $21$, $2024$; and June $30$, $2024$.

**Solution:**

1. Check the direction: reverse chronological means newest to oldest.
2. Compare the years: all three are $2024$ (tie).
3. Compare the months: July is newer than June, so June $30$, $2024$ goes last.
4. The two July dates first differ in the day: $21$ is newer than $8$.
5. The order is July $21$, $2024$; July $8$, $2024$; June $30$, $2024$.

### #3: Primary Number First, Date Second

A registry files by file number in ascending order, then by date in newest-first order when file numbers match. Arrange File $18$, $2024\text{-}11\text{-}25$; File $18$, $2024\text{-}12\text{-}03$; File $21$, $2024\text{-}11\text{-}19$; and File $21$, $2025\text{-}02\text{-}10$.

**Solution:**

1. Compare the file numbers first: $18 < 21$, so both File $18$ records come before both File $21$ records.
2. Compare the File $21$ dates, newest first. The years first differ: $2025$ is newer than $2024$, so File $21$, $2025\text{-}02\text{-}10$ comes before File $21$, $2024\text{-}11\text{-}19$.

:::try
Finish the last step: compare the two File $18$ dates, newest first, then write all four records in filing order.
:::answer
The answer is **File $18$, $2024\text{-}12\text{-}03$; File $18$, $2024\text{-}11\text{-}25$; File $21$, $2025\text{-}02\text{-}10$; File $21$, $2024\text{-}11\text{-}19$**. Both File $18$ dates are in $2024$, so the month decides: $12$ is newer than $11$.
:::

## Traps to Watch For

:::checklist
- "Reverse chronological" or "newest first": start with the most recent date. {#wrong-date-direction}
- December vs. an early month of the next year: compare the year first. {#month-beats-year}
- July $1$ vs. June $15$: compare the month before the day. {#day-beats-month}
:::
