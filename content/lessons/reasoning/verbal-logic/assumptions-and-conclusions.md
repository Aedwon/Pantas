## Core Concept

In analytical reasoning, an **assumption** is an unstated premise that must be true for an argument or statement to hold. A **conclusion** is a logical claim that necessarily follows from given statements.

## Key Rules

- **Valid Assumption:** An assumption is valid if the argument falls apart when the assumption is negated.
- **Valid Conclusion:** A conclusion is valid if it must be true whenever the premises are true.
- **Avoid Overreach:** Do not assume facts outside the provided statement, and do not select conclusions that go beyond what the premises strictly justify.
