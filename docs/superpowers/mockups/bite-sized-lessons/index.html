Bite-sized lessons: the new lesson label, before and after

Preview theme

What changes. Every lesson row and header that shows typed-in minutes ("10 min") shows "Part 2 of 9 · 3 questions" instead. A lesson that is not split yet has no part, so it shows only "5 questions". The end of a part gets a next-part action. The quiz button shows the real question count.

How these were made. Every image is a render of the real Pantas screen with the app's own components, at 390 px (phone) and 1440 px (web), in light and dark. The prototype only changes the label text and adds one button. Sample content is the pilot topic Philippine Constitution: the Bill of Rights as nine parts (2 to 6 questions each) plus one lesson that is not split. "Before" shows "10 min" on every row because 10 is the authored value for the pilot lessons today. Part titles and question counts are sample values. The theme toggle changes only the previews.

Rows in the open topic. Phone: study_topic_section. Web: web_study_layout.

6. Topic ending, and the summed "minutes of material" line (Option A or B)

Still-unread rows (ending_content, web_ending_layout) and the next-topic card.

Finding on the summed minutes. No screen draws a summed minutes line today. The totals "minutes left to read" and "about N minutes of material" exist in code but nothing displays them, so there is nothing to replace on screen. The only place a line like that could sit is the detail line of the next-topic card on the web ending (empty here, as today). Option A adds a count line there ("Four lessons left"; the count is a sample). Option B removes the line, which looks the same as today. The phone ending has no next-topic card, so A and B are identical there. On the phone the unread rows stack the label under the title, and the rows sit tight together.
