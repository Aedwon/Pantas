The splash adds perceived delay: `web/pantas_splash.js:8–12` holds until data settles, then fades for 400ms. Its 8s fallback starts only after bootstrap finishes. Home signals readiness after its full loader completes (`home_today_screen.dart:427`). Uncovering the first useful frame could save **0.4–8s visually**, without accelerating data.

Four synchronous head scripts also delay HTML paint (`web/index.html:59,62,235,237`). Bundle the small boot helpers while preserving their early event handling.

`getRoadmap` and `setExamSettings` **do not request limited-use tokens** (`callable_options.dart:8`). `getBetaAccess` does. It follows auth resolution and blocks Home while enabled. Missing settings cause `getRoadmap → setExamSettings → getRoadmap` (`study_api.dart:72`); combine recovery server-side instead of parallelizing dependent calls. Public roadmap caching already exists.
