B6. Install prompt

How and when the app offers "Install Pantas". Every option follows the same rules.

Android, desktop Chrome and Edge

The browser fires an install event. Pantas keeps it and shows its own "Install Pantas" button. Tapping it opens the browser's install dialog, which Pantas cannot restyle.

iPhone Safari

There is no install event. The same entry point says "Show Me How" and opens the sheet shown further down.

When it shows (all options)

  • After the first finished lesson, never at first open.
  • Only if the browser can install and Pantas is not already installed.
  • Not Now hides it for 30 days (Proposed). A second Not Now stops it.
  • After install, Pantas asks the browser to keep its storage. No screen for that.

Option A. Card on Home Recommended

Where: top of Home, under the greeting.
When: first visit to Home after the first finished lesson.
Good: in the page, not blocking, easy to ignore or dismiss.
Cost: one slot on Home. Nothing else changes.

On iPhone the primary button reads "Show Me How" and opens the sheet below.

Option B. Row in Settings Alternative

Where: its own group at the bottom of Settings.
When: always, while the browser can install and Pantas is not installed.
Good: never interrupts. Also the way back after Not Now.
Cost: smallest. Few people open Settings, so few installs.

Desktop shows the row selected with its detail on the right, like the other Settings boards. On iPhone the row opens the same instruction sheet.

Option C. Offer on the finish screen Alternative

Where: under "Back to Home" on "That's enough for today."
When: once, right after the first finished lesson.
Good: the strongest moment, when the learner just succeeded.
Cost: sits on a completion screen next to the main button. One shot unless B also exists.

iPhone Safari instruction sheet Proposed

Used by: every option, on iPhone only.
Opens from: the "Show Me How" button.
Note: the strip with the Share button is a drawn hint of Safari's toolbar, not Pantas UI.

Offline notice Not in the plan

The plan lists caching but no offline screen. The boards show offline messages only on single actions (for example "You need a connection to sign in."). This optional notice is what caching makes possible: Pantas opens and lessons on the device work with no connection. Without this notice, the app simply behaves as it does today. It clears itself when the connection returns. No red, since offline is not an error.

If someone opens Pantas offline for the very first time, the browser shows its own error page. Pantas cannot style that without extra work.

B7a. HTML Welcome screen

Plain HTML and CSS in the page. It shows to first-time visitors while the app downloads. Returning visitors skip it and see only the logo splash (B5). Board source: OB_Welcome, copy unchanged. Logo animation (pop, then text and button rise) is copied from the board.

Welcome Board

Button: natural width, Title Case, teal. The Enter key hint shows on desktop only.
Theme: follows the device setting on the first visit.

After Get Started, while the app is still loading Proposed

What changes: only the button. It shows a spinner and "Starting…" (the sign-in loading pattern, adapted to a teal button).
Handoff: when the app is ready it opens the onboarding age step on the same background, so nothing jumps. If the app is already ready, the button is never shown in this state.
