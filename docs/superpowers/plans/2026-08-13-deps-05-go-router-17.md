# Dependencies 05: go_router 14 to 17

> **How to work this plan.** Task by task, in order. Commit the moment a task's
> own check passes, before starting the next one.
>
> **Required reading before Task 1:** `AGENTS.md` in full.
>
> **Follow the plan. Do not redesign.** If a step is ambiguous or looks wrong,
> **stop and say so.**

**Goal:** Move `go_router` from 14.8 to 17.x, three majors.

**Tier:** Pro. A routing mistake is invisible until somebody opens that screen.

## Global Constraints

- **Work only inside your worktree.** Run `pwd` before your first write.
- **Never run `flutter test` with no arguments. Never run `flutter analyze`.
  Never run `dart run build_runner`.** You may run a single test file, and the
  routing tests are the point of this plan, so run them often.
- **Never use `&`, `nohup`, or any background mechanism.**
- **Touch `go_router` and nothing else in the pubspec.**
- **Do not change a single route path, name, parameter or redirect rule.** This
  is an API migration. A changed path is a dead link from a notification, and
  nothing in the suite would catch it.
- **`context.push` for anything outside the tab shell. Never `context.go`
  there.** `go` strands the student with no back arrow. This is a standing rule
  in `AGENTS.md` and the migration must not quietly convert one into the other.
- **No AI attribution in commits.**

## Task 2: The routing table

**File:** `lib/app/router.dart`

**Read the whole file before changing any of it.** Then read go_router's
changelog for 15, 16 and 17 and work out what actually moved. Likely areas, as a
starting point and not a promise:

- `GoRouter` construction, `redirect`, and `refreshListenable`
- `GoRoute` builders, `pageBuilder` and `state.pageKey`
- `state.pathParameters`, `state.uri.queryParameters`, `state.matchedLocation`
- `ShellRoute` and anything the tab shell relies on
- `GoRouter.maybeOf` and the extension methods on `BuildContext`

**Rules:**

1. **Paths, names, parameters and redirect conditions stay identical.**
2. **If a construct has no replacement, stop and report it.** Do not invent a
   near-equivalent. Routing is where a plausible invention hides longest.
