## Figure contract for rule writers

Read from the five widgets' `fromSpec` parsers and painters in `lib/core/ui/figures/` on the workstream, not inferred from examples. Unknown fields do not add drawing capabilities.

- `figure-series`: `items` length 2..5, `blank` boolean (default true). Each item requires `form`: square/circle/triangle/pentagon/star. Optional `size`: small/medium/large (default large, scales .62/.82/1); `fill`: white/black or number 0..1 (default white); `dot`: top-left/top-right/bottom-left/bottom-right/top; `dots`: integer 0..5; `edgeLines`: integer 0..5. `line`: finite number in degrees clockwise from up, OR `lines`: 1..4 finite numbers, never both. `rotation`: finite degrees, default 0; `arrow`: up/right/down/left. Rotation applies to the complete item. Lines are radial rays, not full diameters. Fractional fill is the bottom portion before rotation. There is no center-dot position, hexagon, heptagon, octagon, arbitrary dot placement, or smaller-than-small size.
- `figure-matrix`: integer `rows`, `cols`, each 2..3; `cells` length exactly rows*cols, row-major; exactly one literal string `blank`. All other cells use the series item contract, including `lines`, `rotation`, and `edgeLines`.
- `shape-row`: `shapes` length 2..6. Each requires `form`: square/rectangle/rhombus/parallelogram/triangle/circle/pentagon/hexagon/blob. Optional `dots`, `lines`: integers 0..4, default 0; `through`: centre/off, default centre (literal API spelling). Lines are equally angled diameters, shifted together when off-center; only circle cuts are clipped. No size/fill/rotation/arrows/labels or arbitrary polygon vertices.
- `paper-fold`: `folds` length 1..3, each vertical/horizontal, repeated axes accepted. `cut`: hole/notch (default hole); `at`: interior/edge/corner/fold-corner/on-fold (default interior); `sheet`: square/rectangle (default square); `showUnfolded`: boolean, default false. Each fold halves the current packet, retaining its right or bottom half. Cut position is fixed by `at`, not coordinates: corner is inset 12 units from packet top-left; edge is inset 12 from its right side; on-fold is its left midpoint; fold-corner is exact top-left. Hole radius and notch size are fixed. No diagonal fold, variable cut count, cut size, or arbitrary cut location.
- `cube-net`: `cells` length 2..8, unique `[row,column]` integer pairs, both coordinates 0..5. Optional `labels`: one nonempty string of length <=12 per cell, no null entries when supplied. `showFolded`: boolean, default false. Parser does not enforce six connected cells or a valid net. Folded view is a fixed unlabeled cube outline, not an orientation solver or configurable solid. Cannot draw labeled cube views, block assemblies, or cylinders.
