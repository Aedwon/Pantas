# Approved lesson figure style: D, modern flat with depth

Approved by Aedwon on October 25, 2026 from the private page "Lesson Figure Styles" (version 1),
a copy of which is `figure-styles.html`. Reference figures: `fig1-D.svg` (monsoon) and
`fig2-D.svg` (Venn diagram).

Style rules taken from the approved samples:
- Flat shapes with linear and radial gradients for depth; cool palette (deep blue panel, teal and
  sky blue fills, warm orange or sun yellow as the one accent).
- Each figure carries its own rounded panel, so it reads the same on light and dark lessons.
- White labels in Geist (math in KaTeX fonts; see SONNET-FIGURE-INSTRUCTIONS.md), at least 14 px at a 360 px display width.
- Only features the app's SVG library draws: no filters, CSS style blocks, classes, masks with
  filters, external images or fonts, or animation tags.
- The sample's content gaps (no arrow for warm air rising over land) are not part of the style.
