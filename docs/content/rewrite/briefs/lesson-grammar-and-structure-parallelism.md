## Fix these

### 1. `lesson-grammar-and-structure-parallelism|B01|0`
- Rule: B01
- Fix size: small
- Quote:
> "She enjoys hiking and to swim": both "hiking" and "to swim" are perfectly correct phrases individually, but placed together in a list, their mismatched forms break parallelism.
- Problem: The packet's Level 3 record says "enjoy" rejects a to-infinitive complement. In this sentence, "to swim" is therefore not a valid complement of "enjoy," so the example has a verb-pattern error in addition to the parallelism problem.
- Triage reason: 'Enjoys to swim' is wrong for a second reason (enjoy takes -ing); pick a cleaner example.

### 2. `lesson-grammar-and-structure-parallelism|L27|0`
- Rule: L27
- Fix size: small
- Quote:
> **Scan the list for matching endings.** For any list joined by "and" or "or," quickly check whether each item ends the same way (all "-ing," all "to + verb," all plain nouns, and so on).
- Problem: This shortcut gives no limitation for constructions where a marker can be shared, such as Example 3's "how to install, update, and troubleshoot." Without that condition, students may wrongly expect every parallel item to repeat the same visible ending or infinitive marker.
- Triage reason: "Same ending" misleads when a shared "to" covers several verbs, as in Example 3.
