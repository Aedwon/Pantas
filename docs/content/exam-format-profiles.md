# Exam Format Profiles

How each exam's items look, so "realistic exam wording" can be checked against
evidence instead of impression. Used by
[question-style-guide.md](question-style-guide.md) and
[content-checklist.md](content-checklist.md).

## How to use and fill these

- Every entry has a value, a source, the date checked, and a confidence:
  **official** (the organizer's own material), **strong secondary** (a
  reputable source that quotes or describes official material), **weak**
  (unofficial reviewers or recollections), or **unknown**.
- Sources follow [source-policy.md](source-policy.md).
- While an entry is unknown, DepEd test-construction conventions apply: four or
  five similar choices, one main idea per stem, a complete stem. Report the gap.
- A profile shapes format only: choice count, item types, wording style. It
  never overrides correctness rules or the app's constraints. The app shuffles
  choices, so position-dependent choices stay banned. If an exam uses "none of
  the above" or "all of the above", write "None of these" or "All of these".
- Subtest mix and topic weights are recorded only from a published or verified
  source. Never estimate them; leave them unknown instead. The mock exam uses
  them where they exist.
- The coverage audit's first step fills these profiles. Until then, every
  entry is unknown.
