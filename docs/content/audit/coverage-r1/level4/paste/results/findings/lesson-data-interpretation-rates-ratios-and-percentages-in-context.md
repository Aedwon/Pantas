  - Quote: "A positive result is an increase and a negative result is a decrease."
  - Problem: This sign interpretation is not generally correct when the original value is negative. With a negative original value, the percentage-change formula can produce a negative result even when the new value is numerically greater.
- **B03** (Blocker; one read, paste run)

## Accuracy concerns

- "A positive result is an increase and a negative result is a decrease.": The statement is overgeneralized. If the original value is negative, the sign of the computed percentage change does not reliably indicate whether the new value increased or decreased numerically.
