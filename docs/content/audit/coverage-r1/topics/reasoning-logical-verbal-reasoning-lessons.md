Interleaving, alternating operations, recurrence/Fibonacci and linguistic/cyclic letter patterns lack local applications. These are local limits within curriculum/weak leads, not proof that each current exam requires all such extensions.

It does not teach natural-language symbolization, tautology/contradiction classification or general argument-countermodel construction.
