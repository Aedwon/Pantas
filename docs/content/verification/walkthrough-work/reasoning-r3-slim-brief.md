## Rules 3 and 4 for this batch (replace the series wording)

- Chains end at the answer. A filing example compares the entries unit by unit (or digit by digit, or year, month, day)
  and names the unit where they first differ, then ends at the order asked for, written out in full.
- Rules are scoped. Filing rules are conventions, and offices use different ones. Each rule says it is the rule this
  lesson (and the exam's questions) uses, for example "In these questions, ...". Never claim a filing rule holds
  everywhere. Any sentence with every, always, never, only, all, any, none, must or whenever must be true for every case
  these exam questions show, or be scoped.
- The kept Quick Check and the try must need the deciding unit that the example or pair above did not use (for example,
  the entries tie on the unit the demo decided on and differ on the next one), so the answer order cannot be copied from
  the demo's order.
