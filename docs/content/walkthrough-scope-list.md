# Walk-through lesson format: scope list

Made Nov 27, 2026, for the spec revision of Nov 27 (`docs/superpowers/specs/2026-11-25-lesson-walkthrough-standard.md`, "Revision, November 27"): which non-math lessons are step-solving and could get the walk-through format after the Math pilot. A first pass by a bulk model (Haiku 5.5) from each lesson's title and opening lines; "unsure" rows and every row a lead picks up must be re-checked by reading the whole lesson. Mathematics is in scope already and is not listed. No file has an exams field, so the exams column is blank.

Source: the live content root (`content/cse-question-fixes-r1` worktree), `content/lessons/`.

## 11. Method

- Retired files: a file is retired when its front matter has `status: retired`. That field marks 76 files in scope, which I skipped. The `isActive: true` field appears on every file, so I did not use it. A `replacedBy` list names the successors of retired files.
- Active files: 488. I read the title and the first 60 lines of each through 10 Haiku subagents, then compiled their output. I re-read three classifications myself (Lenz's law, None and May, VSEPR with two or three groups); all three matched. I did not re-read the rest.
- Exams: no front matter file has an exams or tags field, so the Exams column is blank.
- Figures: this flag is a judgment from the first 60 lines. As a cross-check only, 154 active files contain an illustration marker. I did not use that marker for the flag.
- Unclassified: none. 43 items are marked unsure in the tables, all as close calls.
