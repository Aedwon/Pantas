# Screens

Every approved board, grouped the way the canvas groups them. Open the board in a browser to see it move;
the screenshot is the still. Route is the app route in `lib/app/router.dart` (a "new" route does not exist yet).
Specs are the closest existing specs; where a board and a spec disagree, the board and `DECISIONS.md` win.
