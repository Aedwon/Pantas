Pantas: every screen

Wireframe map of all specced surfaces. Structure, hierarchy and flow, not final type or color. Read each row left to right.

How to read this. Each row is one path through the app. Grey blocks are content, the green block is the single primary action on that screen, amber marks a deadline or fixed point, rust marks a destructive action or a loss.
Green appears once per screen at most. Where a screen has none, that screen has no primary action by design.
ANIM in the corner means that screen has a motion behavior; tick "Play animations" to see it.
What this is not. Not final typography, spacing or color. Those live in the specs and in the review plates.
